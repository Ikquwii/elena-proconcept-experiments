# Макеты

20 новых интерактивных макетов: 10 для портфолио Елены Белоусовой и 10 для Pro Concept.

Открыть: https://ikquwii.github.io/elena-proconcept-experiments/

Эта подборка выделена в самостоятельный сайт из общего набора концепций. Здесь опубликованы только двадцать новых направлений.

Главная страница — `index.html`. Новые варианты начинаются с `new-elena-` и `new-proconcept-`. Можно сохранять понравившиеся макеты в избранное на своём устройстве.

Новые страницы спроектированы прежде всего для телефона: обычная прокрутка, управление касаниями, крупные кнопки, полноэкранный просмотр фотографий и отключение анимации. Исходная нейтральная палитра сохранена; фотографии остаются цветными.

92 реальные фотографии с исходных сайтов сохранены локально в двух размерах WebP; суммарный вес 184 файлов — около 11,7 МиБ. Ниже первого экрана используется отложенная загрузка. GSAP, ScrollTrigger и Lenis также локальные; шрифты загружаются с Google Fonts.

Статические HTML-страницы, сборка не требуется. Публикация через GitHub Pages из корня ветки `main`.

Контактные ссылки открывают почтовое приложение. Серверной обработки заявок нет. Фотографии и названия проектов принадлежат их правообладателям; публикация демонстрирует направления редизайна.

Исследование и принципы: [DESIGN-NOTES.md](DESIGN-NOTES.md).
