# Макеты

Витрина четырёх дополнительных усиленных версий и двадцати ранее созданных макетов: портфолио Елены Белоусовой и Pro Concept.

Открыть: [elena-proconcept-experiments](https://ikquwii.github.io/elena-proconcept-experiments/).

## Четыре усиленные версии

В верхней части главной страницы собраны новые варианты:

| Версия | Механика |
|---|---|
| [Orbit — Éventail Amplified](wow-elena-orbit.html) | Объёмная орбита отпечатков: раскрытие, разлёт и сборка при прокрутке. Свайп меняет выбранную фотографию. |
| [Oblique — Kinetic Edition](wow-elena-oblique.html) | Диагональная лента фотографий пересекает экран и меняет композицию; движение продолжается в сериях ниже. |
| [WORLD STAGE](wow-proconcept-stage.html) | Фотографическая ширма проходит три акта; выбранный отпечаток разворачивается для просмотра. |
| [Four Views — Immersive](wow-proconcept-fourviews.html) | Контактный лист раскрывается в WebGL-пространство, камера меняет ракурс, выбранная фотография выходит вперёд. |

Двадцать страниц с префиксами `new-elena-` и `new-proconcept-` сохранены как самостоятельные варианты. Первые восемь концепций находятся на отдельном сайте и в этот экспорт не входят. Главная страница — `index.html`; избранное сохраняется на устройстве посетителя.

## Материалы и запуск

92 реальные фотографии с исходных сайтов сохранены локально в двух размерах WebP: 184 файла занимают около 11,7 МиБ. Цвет фотографий сохранён; полный кадр доступен в общем просмотрщике.

GSAP, ScrollTrigger и Lenis находятся локально. Four Views дополнительно использует локальный Three.js **0.186.0** из официального npm-пакета; происхождение, SHA-512 tarball и контрольные суммы файлов записаны в [versions.json](assets/vendor/three/versions.json). Остальные три усиленные версии используют CSS-преобразования и GSAP. Шрифты загружаются с Google Fonts.

WebGL отрисовывается по изменениям состояния через одноразовый вызов GSAP ticker. DPR ограничен 1,5 на узком экране и 2 на широком; drawing buffer — примерно двумя миллионами пикселей. При уменьшенном движении или недоступной графике Four Views показывает обычную фотогалерею.

Это статические HTML-страницы: сборка не требуется. Для локального просмотра нужен HTTP-сервер; публикация — GitHub Pages из корня ветки `main`. Контактные ссылки открывают почтовое приложение; серверной обработки заявок нет.

## Проверка

Для четырёх усиленных версий проверены макеты при ширине viewport **360, 390, 430 и 1280 px**: горизонтального переполнения нет. Интерактивные сцены, полные кадры и промежуточные состояния проверены на 390 px; WebGL также просмотрен на 360, 430 и 1280 px. Проверены режим без анимации, повтор входной анимации и избранное в каталоге. Физический iPhone не проверялся. Локальные ссылки, пути изображений и синтаксис подключаемых JS проверены; WebGL lifecycle прошёл отдельное ревью.

Фотографии и названия проектов принадлежат их правообладателям; подборка демонстрирует направления редизайна. Подробности решений: [DESIGN-NOTES.md](DESIGN-NOTES.md).
